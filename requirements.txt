# EcoSecurity: dependências com versões fixas, para o ambiente ser reproduzível.

# Visão computacional
# opencv-contrib-python, e não opencv-python: o módulo cv2.face (LBPH e os
# landmarks FacemarkLBF da piscada) só existe no contrib, e os dois pacotes no
# mesmo ambiente conflitam sem aviso. Série 4.10, validada com LBPH, KCF e
# FacemarkLBF.

# abaixo de 2.0 por compatibilidade binária com o OpenCV 4.10
numpy==1.26.4

# Interface
# Qt 6: escala de DPI automática, QThread para a captura, tabelas e o PDF da via
# do termo (QPdfWriter). Traz o shiboken6.

# Componentes no visual do Windows 11 (navegação, cartões, notificações, ícones).
# Licença GPLv3. Traz junto PySideSix-Frameless-Window e darkdetect.
PySide6-Fluent-Widgets==1.11.3
# Proteção dos segredos pelo Windows (DPAPI) e atalho com ícone. Só no Windows.
pywin32==312; sys_platform == "win32"

# Acervo
# Desenho dos relatórios do acervo. O cv2.putText não escreve acentos; o Pillow
# escreve, com as fontes do Windows (Segoe UI).

# Planilha analítica (XLSX) do painel: exportação do nível 2, com aba de rastreio.

# credenciais fora do código (.env)

# Banco de dados
# driver oficial da Oracle. Sem ORM: o SQL fica visível em sql/ e

# Testes
